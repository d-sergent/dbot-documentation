---
description: Recherche dans la base RAG D-Bot
---

Recherche les informations demandées dans la base vectorielle LightRAG du D-Bot. Utilise le wrapper `/opt/homebrew/bin/rag` pour interroger le serveur MCP dbot-rag.

La recherche par défaut retourne le contexte précis (mode local). Utilise `--search` pour une recherche sémantique hybride.

Présente les extraits pertinents de manière synthétique.
