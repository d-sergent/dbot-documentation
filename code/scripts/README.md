Ce dossier contient l'ensemble des scripts exécutables du robot organisés par sous-système.

## 🗂️ Structure des Dossiers de Scripts

```
scripts/
├── vision/      ← Tests Triade Visuelle (YOLO-World, OAK-D Pro, Export TensorRT)
├── motors/      ← Qualification Moteurs RobStride (Cou Pan/Tilt RS-05)
├── audio/       ← Qualification Audio & VAD ReSpeaker
├── system/      ← Diagnostic système, statut bus CAN et vérification matériel
└── behaviors/   ← Démonstrations et comportements autonomes
```
